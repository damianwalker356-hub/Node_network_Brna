# Data, weights, and large files

The BRNA prototype's synthetic observations are generated in `src/brna/proto.py` using NumPy's seeded generator. The historical JSON run record was supplied with the repository; its original generation provenance is limited to fields present in that record.

The local studio optionally depends on `reasoning-gym==0.1.25` from [open-thought/reasoning-gym](https://github.com/open-thought/reasoning-gym/tree/v0.1.25) (Apache-2.0 at the repository root; tag commit `21e6d2a9a581b3e11aafe711abfd37402f8482d`). It generates tasks procedurally at runtime; no upstream corpus files are copied into this repository. The selectable subset is intentionally limited to `basic_arithmetic` and `leg_counting`. Each task's generated answer is checked with the package-provided `score_answer` verifier. Generated examples are bounded by the studio to at most 128 per request and a 50,000-character accumulated training corpus.

Reasoning Gym's upstream `NOTICE.txt` documents task/code/data contributions that have additional licenses, including GPL-3.0 ACRE. This integration does not expose ACRE or the full upstream task registry. A future redistribution that bundles Reasoning Gym must preserve its Apache license and applicable notice/third-party terms. The repository-level `LICENSE` remains an owner-selection placeholder; this change does not declare the entire BRNA repository open source.
