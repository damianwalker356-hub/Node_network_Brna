# Status: Draft

## Purpose and scope

Establish a repeatable, software-only prototype verification path. The current source inputs are a toy backbone, synthetic task, and limited recorded experiments. No network egress, actuators, biological interface, or hardware connection is in scope.

## Technical approach

Use a small NumPy message passing prototype and synthetic distributed-interaction classification problem. Compare message passing, quantized messages, no communication, and single-model baselines when records are available. Later real backbones and tissue interfaces are out of scope.

The local studio additionally supports a bounded cooperative agent experiment: up to eight independent character-level RNN nodes share user-provided training text and exchange outputs in two passes. User ratings produce discounted episodic REINFORCE updates. This is a functional training path, not a foundation-model training program. Training data is limited to 50,000 shared characters and model quality has not been measured. Frontier-level claims require a separately funded architecture, licensed corpus, compute plan, evaluation suite, safety review, and independently reviewed results.

An optional pinned Reasoning Gym dependency supplies procedural arithmetic/leg-counting examples and algorithmic answer scoring. The studio can train nodes on generated question/answer pairs and use a verifier score as an RL reward. This small, curated task integration is not a broad reasoning benchmark.
