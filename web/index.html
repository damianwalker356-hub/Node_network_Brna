SHARED TRAINING

Train every model node

Training data is applied separately to each node's from-scratch character model. Shared text is capped at 50,000 characters; this is a small experimental system, not frontier-scale training.

Reasoning Gym is an optional local dependency.

Training requires at least one model node.

SHARED THOUGHT

Run a collective turn

Each model produces a private draft, then every model gets a shared pass with the other nodes' drafts. The last node's revised text is returned as the network response.

Reward feedback updates the sampled responses with discounted episodic REINFORCE; evaluate carefully.

This local CPU-oriented prototype uses character-level RNN nodes and simple episodic policy gradients. It does not provide frontier-model language ability, robust reasoning, or a validated RL benchmark. Training quality depends on user data and available compute.

DIFFERENTIABLE LATENT GRAPH

Graph unavailable

Each trained model encodes its context as a bounded latent message. The directed graph learns transforms and edge gates from labeled actions. Supply one text context per current agent for every example.

Train every model node before fitting the latent graph.

CLOSED-LOOP POLICY

Run a graph action episode

Start an episode, request a graph-selected action, evaluate it in your software task, then submit its reward before continuing. This service does not execute the task environment.

Graph actions require trained nodes and an active episode.

VERIFIABLE REWARD

Run a generated reasoning task

Generate a seeded task, run the current agent network, score its response with the task verifier, and apply that score as an RL reward. The generated item is independently reproducible from task, seed, and index.

A verified task episode requires at least two trained model nodes.
