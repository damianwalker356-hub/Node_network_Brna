Example dataset

Edit the examples as JSON arrays of numeric input and target values. The demo data is an architecture check, not evidence of BRNA performance.

Targets for one output must be between 0 and 1. Multi-output targets must be non-negative and sum to 1.

EVOLUTIONARY SEARCH

Optimize by fitness

Each candidate is a set of network weights. Fitness is negative cross-entropy loss on the selected examples; fitter candidates reproduce with mutation.

Fitness is measured against the training examples only.

EVALUATION

Network outputs

Train or evaluate the model to view output probabilities and loss.

Training examples are local demonstrations. Training loss on these examples does not establish generalization, safety, or fitness for real-world BRNA tasks.
